# Estante Virtual — site

Site estático (GitHub Pages) do app Android pessoal **Estante Virtual**, com a página inicial e a política de privacidade usadas na tela de consentimento OAuth do Google.

- Página inicial: https://brunorodrigues85.github.io/estante-virtual-site/
- Política de privacidade: https://brunorodrigues85.github.io/estante-virtual-site/privacidade.html

Contém apenas HTML, CSS e um ícone SVG. O código do app fica em outro repositório (privado).
